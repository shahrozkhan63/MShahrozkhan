ADJD Judicial Kiosk

Abu Dhabi Judicial Department Android POS application enabling fine payments through EMV card processing — including Emirates ID integration, case number inquiry, and 3D Secure payment flow across 1000s of daily judicial transactions.

Multilevel Technologies · Abu Dhabi, UAE 2019 – 2020 1000+ Daily Transactions
Project Overview

ADJD is an Android POS application for the Abu Dhabi Judicial Department. Customers can inquire about and pay judicial fines through multiple identification methods including Emirates ID, Case Number, and Reference Number.

The application integrates EMV card reading (Swipe, Insert, Tap) with a 3D Secure payment gateway. Emirates ID cards can be physically inserted into the POS device to automatically fetch customer details and associated fine records.

All services are consumed via REST/SOAP API network calls. Once the service responds, data is manipulated within the Android application and proceeds through to payment completion.

Services Available
  • Public Prosecution Services — case inquiry and fine payments
  • Traffic Fine Reduction — eligible fine reduction processing
  • Reference Number — fetch details and proceed to payment
  • Case Number — lookup associated fines and pay
  • Emirates ID — insert chip card to auto-fetch customer details
  • EMV Cards — Swipe, Insert, Tap — Euro, Master, Visa
  • 3D Secure OTP — bank-sent OTP before transaction completes

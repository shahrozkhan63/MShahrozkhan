Multilevel Technologies · Dubai, UAE 2019 – 2020 1000+ Daily Transactions
Project Overview

Dubai RTA Android POS application is a payment service provider with which customers can pay fines, renew or replace driving licenses, renew vehicle registration cards, and print certificates.

The POS device accepts EMV (Euro, Master, Visa) cards via Swipe, Insert, or Tap. All payments are 3D Secure — an OTP is sent to the customer's registered mobile number before transaction completion.

Transaction receipts are sent via email and SMS. The entire service is consumed through REST API network calls that fetch, manipulate, and display data on the Android POS device.

Services Available
  • Pay Fines — by Traffic File Number, Driving License, Plate Number, or Fine Number
  • Vehicle Registration — renewal and replacement of lost/damaged card
  • Driving License — renewal and replacement of lost/damaged license
  • Certificates — Ownership, Non-Ownership, Clearance, Insurance Refund, Driving Experience
  • 3D Secure Payments — OTP-verified EMV card transactions

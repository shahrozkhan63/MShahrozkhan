Dubai Taxi Infotainment System

DTC (Dubai Taxi Corporation) in-cab infotainment application deployed across 800+ Dubai taxis — delivering real-time dynamic content, Google Maps integration, weather, news, trip data, and integrated RTA payment services to passengers.

Multilevel Technologies · Dubai, UAE 2019 – 2020 800+ Taxis Deployed
Project Overview

DTC is an infotainment application installed on Android POS devices fitted in Dubai taxis. Its purpose is to keep passengers engaged with dynamic content while providing the driver with real-time trip data.

All content is fully dynamic — fetched from dedicated APIs for each section and rendered on the Android POS screen. There is a separate API per content type: banners, videos, news, weather, maps, and payment services.

The application also integrates full RTA payment capabilities — passengers can pay fines, renew driving licenses, and renew vehicle registrations directly from the taxi during their trip.

Content & Services
  • Dynamic Banners — latest offers, promotions, and ads rendered in real time
  • Videos — government Smart Teller videos, restaurant offers, events, promotions
  • Weather Forecast — live weather data fetched via API
  • Driver Trip Details — start/end time, fare, payment method
  • News Bulletin — live news feed from multiple sources
  • Google Maps — live route with traffic updates and distance remaining
  • RTA Services — pay fines, renew driving license, renew vehicle registration
